DOKUMENTATION

So richtest du BotConfig ein.

Die Website ist der Client. Discord OAuth und alle geheimen Schlüssel gehören auf das Backend — niemals in den öffentlichen Website-Code.

1. Discord OAuth

Im Discord Developer Portal unter OAuth2 die Redirect-Adresse eintragen:

Client-ID: 1446188210794401883

2. Wispbyte Umgebungsvariablen

Diese Werte im Backend setzen:

WEBSITE_URL=https://singhsamuel285-tech.github.io/BotConfig/
WEBSITE_ORIGIN=https://singhsamuel285-tech.github.io
DISCORD_CLIENT_ID=1446188210794401883

Zusätzlich werden DISCORD_CLIENT_SECRET und ein starker API_SECRET benötigt. Diese beiden Werte nicht veröffentlichen.

3. API-Verbindung

Die Website erwartet die Backend-Routen für Discord-Login, Bootstrap, Serverliste und Konfiguration. Die API muss HTTPS verwenden und CORS für die oben genannte Website-Origin erlauben.

SUPPORT

Wir helfen dir weiter.

Hier findest du die wichtigsten Schritte zur Fehlerbehebung für Samuel Studios BotConfig.

Discord-Login schlägt fehl?

Prüfe Client-ID, Client-Secret auf dem Backend, Redirect-URL und ob der API-Server online ist.

Dashboard bleibt leer?

Prüfe in den Wispbyte-Logs, ob die API gestartet wurde und ob die Backend-Adresse stimmt. Teile niemals deinen Bot-Token oder Secrets.

Kontakt

Verlinke hier deinen offiziellen Support-Discord oder ein Support-Ticket, sobald du die richtige URL festgelegt hast.
